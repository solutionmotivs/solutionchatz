# hs2022.csv

Harmonized System 2022 nomenclature (2-, 4- and 6-digit levels), as published in the open dataset
<https://github.com/datasets/harmonized-system> (version 2022.0), itself extracted from the UN Comtrade classification API.
Licence of the dataset: Open Data Commons Public Domain Dedication and License v1.0 (ODC-PDDL-1.0).
The HS is maintained by the World Customs Organization; this file is a convenience copy for search and validation, not an official publication.

India's 8-digit ITC-HS (DGFT/CBIC) and any national tariff lines beyond 6 digits are NOT in this file: Vaulte accepts an 8-10 digit code
only when its first six digits exist here, and cannot confirm the national extension.
